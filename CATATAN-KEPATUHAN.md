# Catatan Kepatuhan — Mining VRSC di Termux

Tujuan file ini: menjelaskan cara pakai repo ini yang paling sesuai
dengan kebijakan GitHub, supaya risiko di-flag sekecil mungkin.
File ini bukan jaminan hukum dan bukan jaminan akun tidak akan
pernah di-suspend. GitHub tetap punya diskresi penuh atas akun
dan konten di platformnya.

## Yang BOLEH dilakukan

- Menjalankan script ini di perangkat Android kamu sendiri lewat Termux.
- Meng-clone repo ini sekali, untuk dipakai sendiri.
- Mengubah pool atau thread sesuai kemampuan HP kamu sendiri.
- Membaca saldo, worker, dan riwayat pembayaran dari API publik pool.

## Yang TIDAK BOLEH dilakukan dengan repo ini

1. **Jangan mining lewat GitHub.**
   Jangan pernah menjalankan miner lewat GitHub Actions, GitHub
   Codespaces, GitHub Pages, atau server GitHub lainnya. GitHub
   melarang cryptomining lewat Actions dan Codespaces. Repo ini
   sengaja TIDAK berisi workflow Actions apa pun — jangan ditambahkan.

2. **Jangan mengotomasi GitHub.**
   Jangan memakai bot, script massal, atau aktivitas otomatis
   berulang untuk push, star, follow, issue, atau aksi lain di
   GitHub. Pakai repo ini secara manual, dengan kecepatan manusia
   biasa.

3. **Jangan menjanjikan penghasilan.**
   Jangan mempromosikan repo ini sebagai cara cepat kaya, sumber
   penghasilan utama, airdrop, atau investasi. Hasil mining HP
   itu kecil, tidak stabil, dan tidak bisa dijanjikan.

4. **Jangan memakai akun lain untuk mengakali pembatasan.**
   Jangan membuat akun GitHub tambahan untuk mengulang konten
   yang sudah di-suspend, dan jangan memakai repo ini untuk
   mengakali pembatasan akun mana pun.

5. **Jangan membagikan kunci.**
   Jangan pernah memasukkan seed phrase, private key, password,
   atau file `.vrsc_wallet` ke repo, issue, atau komentar.
   Yang dipakai hanya alamat wallet publik yang diawali `R...`.

## Tentang repo ini

- Repo ini bukan produk resmi LuckPool atau Verus, dan tidak
  terafiliasi dengan keduanya.
- Mining tidak dijalankan di GitHub. GitHub di sini hanya tempat
  menyimpan script, seperti menyimpan kode biasa.
- Kalau GitHub mengubah kebijakan atau meminta perubahan,
  ikuti permintaan itu — jangan mencoba mengakali dengan
  nama, akun, atau repo baru.
